# App icon / portrait options

Full-resolution crops (541 × 541) of a 2 × 2 sheet of painted portraits, kept for trying out later (e.g. a character selector).
Not served by the game — `public/icons/` holds the icon actually in use.

| File | What |
|---|---|
| `village_boy_smile_sword.png` | Village boy smiling, sword over his shoulder — **the current app icon** (`public/icons/*`) |
| `village_boy_serious.png` | Village boy, serious look |
| `monster_pink.png` | Pink horned monster with blue fur |
| `frog_man.png` | Frog man |
